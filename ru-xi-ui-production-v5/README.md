# 入戏档案 · IP 配色 1:1 UI 交付包

按顺序打开：

1. `docs/Cursor-逐屏还原与上线对接提词.md`：交给 Cursor 的执行说明；业务原附件已附在 `docs/业务规格-v2.0-原附件.md`。
2. `reference/approved-design.png`、`reference/ip-brand-palette.png`：已确认布局与新 IP 色板。
3. `screenshots/`：35 张运行时代码预览截图，含登录、答题、结果、主题、商家等。这里是真实浏览器渲染的预览，不是已上线小程序。
4. `preview/index.html`：本地可交互原型。启动 `python3 -m http.server 8000 --directory .`，访问 `http://localhost:8000/preview/`。预览所有身份、邀请、主题和预约动作均是演示。
5. `assets/`：空白档案夹底图、可复用双人透明层、示例单人图、IP 字样和可编辑小图标。

**设计依据优先级：** 本包新 IP 配色与人物样式 > 已确认的四屏布局与操作结构 > 随附业务规格 v2.0-dev-spec。品牌变更覆盖了已确认图里的橙色主操作，主图橙色按钮不能保留。

**交付边界：** 没有收到现有微信小程序源码、正式微信身份能力、后端和商家资料，因此包内是可交互的视觉参考及 Cursor 工程实施规范，不代表原项目已经完成真机或预约联调。正式人格图片待用户另行接入。

## 按钮样式修订（2026-09-26）

全流程主次按钮统一使用扁平样式：无立体阴影、黑色粗边和按压位移。按下只改变背景色，禁用有独立浅灰紫配色；色值与组件约束见 `docs/design-tokens.json`。截图和参考拼版已同步更新。
